# 红利股票跟踪 8.16（云端版）

每天自动抓取一次红利相关股票的关键指标，生成可在手机 / 电脑浏览器查看的网页。

## 功能

- **股票列表表格**：每行一只股票，展示代码、名称、现价、涨跌幅、**近1月%**、**近3月%**、**股息率TTM**、**市盈率TTM**、**市净率**、**近5年PB均值**、**总市值**、**ROE**、**预期收益①**、**预期收益②(5年PB)**、行业、来源标签，支持搜索和点击表头排序。
- **个股详情**：点击任意股票进入，展示指标卡片 + **K线图**（默认显示近半年，可拖拽缩放看更多；支持 **日K / 周K / 月K** 切换；均线 MA5/10/20/60、BOLL、DMI 可开关；**除权除息日在K线上标注 S，悬停显示分红方案**），以及股息率 / 市盈率 / ROE 历史走势。
- **公司信息模块**：在个股详情内新增，按板块展示：① 控股股东与实际控制人（名称后加 **（国有）/（民营）** 小括号标识是否国资）；② 分红数据（**股息率TTM、近5年平均股息率、每股分红金额**，以及每年分红比率、每股分红、近5年平均分红额度）；③ 财务绩效指标（关键 / 盈利 / 风险三组，**默认展示最新年报**，可切换 **年报 / 一季报 / 中报 / 三季报** 四种报告期；同比数据以 **（+x.x%）** 小括号紧跟数值展示；点击任一指标，图表**跟随插入到该指标行下方**，以「柱状图(数值) + 折线图(同比增长率)」双轴展示；财务数据收录 **2016 年至今**）；④ 高管增减持明细；⑤ 公司简介。
- **首页排名区块**：列表上方多榜单 ——（1）**银行股息率 Top10**；（2）**连续分红≥5年 · 近1月涨幅 Top10**；（3）**连续分红≥5年 · 近1月跌幅 Top10**；（4）**连跌7天 / 连续7天阴线 / 连续5天跌破布林下轨**；（5）**近1年高管增持排名表**（全宽表格，按最近增持日期倒序，点击进入个股详情）。
- **标签筛选页**：标签栏**移除“基金持仓”**，**新增“国有企业”**；点击任意标签（含“国有企业”）打开**站内标签页**，列出所有带该标签的股票。
- **浏览器返回**：进入个股详情 / 标签页后，点页面“← 返回列表”按钮或浏览器**返回键**，均回到上一页（基于 URL hash 路由）。
- **红利/宽基基金页**：顶部「红利/宽基基金」标签打开独立列表页（`#/funds`），自动筛选**红利类基金 + 宽基指数基金**（沪深300 / 中证500 / 中证1000 / 上证50 / 创业板指 / 科创50 / 深证100 / 上证180 / 中证800 等，**剔除行业/主题/海外/债基/货基**）；每行展示 **净值日期、当天涨跌幅、近1/3/6/12月涨跌幅、近12月分红次数、分红比率**（近12月每份分红 ÷ 当前净值）、**市盈率、市净率、当前规模、过去1/3/6/12月规模**（过去规模后括号显示「当前−过去」差值与增减%，**红涨绿跌**），可搜索、可点表头排序；点任意一行进入 `#/fund/CODE`，用 ECharts 画**该基金自身的净值走势**。数据源：天天基金 pingzhongdata（净值/规模/分红）+ 乐咕乐股 index-basic（指数 PE/PB/股息率），均免登录。
- **拼音搜索**：主搜索框支持股票/基金名称的**拼音首字母缩写**（如输入 `cjdl` 找到“长江电力”）。
- **每日自动更新**：GitHub Actions 每天 **16:30 和 21:30（北京时间）** 各自动抓数并部署一次（16:30 保证当天估值与K线已发布，21:30 作为晚间补跑），手机外网随时可看，无需电脑开机。**K线按数据源最新交易日更新**（探针判定，估值数据晚发布也不影响K线当天到位）。公司基本面（控股股东 / 分红 / 财务绩效 / 高管增减持 / 简介）已纳入同一 daily-update 流程，带 30 天缓存、每日只刷新过期项，不会全量重抓 992 只股票。基金页“当天涨跌幅”由 daily-update 每日轻量刷新。

## 股票池来源

1. **红利类型基金近5年（2020年至今）前十大持仓**（天天基金/东方财富 F10 数据），凡被持有过的股票全部纳入；
2. **红利指数成分股**：中证红利、红利低波、深证红利、上证红利、红利低波100（新浪财经最新成分）；
3. **高股息筛选**：近12个月已实施现金分红计算的股息率TTM ≥ 3% 且总市值 ≥ 100 亿元的股票；
4. 东财“红利股 / 红利破净股”概念板块成分（接口偶尔限流，失败会自动跳过）；
5. **分红质量过滤**：剔除已退市/无行情的股票；剔除近3年（含今年）任一年度未实施现金分红的股票（0分红自然也被剔除）。

## 指标口径

| 指标 | 来源与口径 |
|---|---|
| 股息率TTM | 近12个月已实施现金分红合计 ÷ 最新收盘价（东方财富分红数据中心） |
| 市盈率TTM / 市净率 / 总市值 | 东方财富估值数据中心（PE_TTM / PB_MRQ / 总市值） |
| ROE | 最新报告期加权净资产收益率（东方财富业绩报表） |
| 近1月% / 近3月% | 最新收盘价相对 21 / 63 个交易日前收盘的涨跌幅（由日K线计算） |
| 近5年PB均值 | 近5年（今往前5个自然年，约68个月）各月末 `收盘价 ÷ 当年每股净资产(BPS)` 的算术平均（BPS 取最新年报，按年向前取最近值） |
| 预期收益① | `当前股息率(小数) + (每股收益 − 每股分红金额) × 当前市净率 ÷ 当前股价` |
| 预期收益②(5年PB) | 同上，但其中市净率改用 **近5年PB均值** |
| 国有企业标签 | 实际控制人 / 控股股东名称命中国资关键词（国资委 / 国有 / 国务院 / 财政部 / 汇金 / 证金 / 社保基金 / 中国烟草 / 中央汇金 等）即标记为“国有企业” |
| 财务绩效同比 | 同报告类型上一年同期数值计算的同比增长率，以 **（+x.x%）** 小括号紧跟数值展示 |
| K线 | 东方财富前复权日K线（MA/BOLL/DMI 由网页端计算） |
| 板块市值排名 | 按估值数据中的行业板块汇总（涨跌幅来自东财行业板块行情） |
| 基金近1/3/6/12月涨跌幅 | 天天基金单位净值序列：最新净值相对 N 个自然月前最近交易日净值的涨跌幅（净值已含分红再投口径） |
| 基金近12月分红次数 / 分红比率 | 取净值序列中的派现记录：次数 = 近12个月派现次数；**分红比率 = 近12个月每份派现合计 ÷ 当前单位净值** |
| 基金市盈率 / 市净率 | 该基金**跟踪指数**的加权平均 PE / PB（乐咕乐股指数估值）；指数无公开数据时显示“—” |
| 基金规模及差值 | 天天基金季度规模序列（亿元）；「过去N月规模」取该时点最近一期季度值，小括号内为「当前规模 − 过去规模」的差值与增减%（红涨绿跌） |

## 部署步骤（约10分钟）

1. **注册 GitHub**：https://github.com/signup ，登录。
2. **新建仓库**：点右上角 + → New repository，仓库名随意（如 `dividend-tracker`），选择 **Public**（GitHub Pages 免费版要求公开仓库；数据是公开行情，无隐私问题），不要勾选任何初始化文件。
3. **本机推送**（已装 git 的话在项目目录执行）：
   ```
   git init
   git add .
   git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
   git push -u origin main
   ```
   推送时按提示输入 GitHub 用户名和 Personal Access Token（Settings → Developer settings → Tokens → 生成一个勾选 repo 权限的 token，作为密码输入）。
4. **开启 GitHub Pages**：仓库页面 → Settings → Pages → Source 选择 **GitHub Actions**（保存）。
5. 等第一次 Actions 运行（仓库 → Actions → daily-update → Run workflow 可手动触发一次），完成后访问：
   `https://<你的用户名>.github.io/<仓库名>/`

## 日常使用

- 每天 16:30 自动更新（21:30 补跑一次），直接刷新网页即可看到最新数据。
- 想看更多历史K线：页面图表下方有滑块，可缩放。
- 手动触发更新：仓库 → Actions → daily-update → Run workflow。
- 想更新股票池（基金持仓变化/新增高股息股）：本机执行 `python pipeline/build_watchlist.py`，把 `data/meta/watchlist.json` 和 `data/meta/fund_holdings.json` 提交推送即可（也可在 Actions 里手动跑，以后可加）。
- 不想在本地跑也没关系：仓库 → Actions → **build-watchlist** → Run workflow，即可在云端重建股票池（约5~10分钟），完成后下次每日更新自动采用新股票池。
- 公司基本面首次初始化 / 全量重建：本机执行 `python pipeline/build_company.py`（可加 `--limit N` 或 `--force`），或在云端 **Actions → build-company → Run workflow** 手动触发（默认 30 天缓存，日常无需手动跑）。

## 股息率阈值提醒（推送到微信）

每天数据更新后，系统会自动对比今日与昨日股息率，一旦发生“跌破 / 涨破”你设定的阈值，就推送一条微信提醒。

### 配置提醒规则

编辑 `data/meta/alerts.json`，例如：

```json
{
  "rules": [
    {"code": "600900", "name": "长江电力", "dy_below": 4.0, "dy_above": 5.5},
    {"code": "601088", "name": "中国神华", "dy_below": 4.5}
  ]
}
```

- `dy_below`：股息率跌破该值（%）时提醒；
- `dy_above`：涨破该值（%）时提醒；两者可只填一个。
- 保存后推送到仓库即可（也可以直接在 GitHub 网页上改这个文件）。

### 配置推送渠道（二选一）

**方式一：Server酱（推荐，最省事）**
1. 打开 [sct.ftqq.com](https://sct.ftqq.com)，用 GitHub 账号登录，复制你的 SendKey（`SCT` 开头）；
2. 仓库 → Settings → Secrets and variables → Actions → **New repository secret**：名称填 `SERVERCHAN_KEY`，值粘贴 SendKey；
3. 按网页提示关注“方糖”公众号即可收到消息（免费版每天有消息条数限制，够日常提醒用）。

**方式二：企业微信群机器人（免费不限条数）**
1. 下载“企业微信”App，注册一个免费企业（个人即可）；
2. 建一个群（可以只有自己），添加**群机器人**，复制 Webhook 地址；
3. 在仓库 Secrets 里新建 `WECOM_WEBHOOK`，粘贴 Webhook 地址。

两个渠道都配置时优先用 Server酱。配置好之后，下次 daily-update 运行（或手动 Run workflow）就会生效。

## 本地运行（可选）

需要 Python 3.10+，无需安装第三方库（全部用标准库）：

```
python pipeline/build_watchlist.py   # 构建股票池（一次性，约10分钟）
python pipeline/update_daily.py      # 抓当天数据
python pipeline/funds.py             # 构建红利/宽基基金页数据（约10分钟，可加 --limit N 试跑）
```

本地预览网页：在项目根目录执行 `python -m http.server 8000`，浏览器打开 `http://localhost:8000`。

> 注：K线 (`data/kline/`) 与**基金净值** (`data/fund_nav/`) 属大文件、每天全量重写，由云端任务每天现场生成并打包部署，**不提交进仓库**；**公司基本面** (`data/company/`) 会提交进仓库并带 30 天缓存，每天仅增量刷新过期项，因此仓库体积可控。仓库里长期保留：股票池、指标历史、公司基本面、基金列表 (`data/funds.json`)。

## 说明

- 数据来自公开免费接口（东方财富、新浪财经、天天基金），仅供学习参考，不构成投资建议。
- 周末/节假日无新交易日数据时会自动跳过，不产生无效更新。
- 若某只股票长期停牌或已退市，对应指标显示“—”。
