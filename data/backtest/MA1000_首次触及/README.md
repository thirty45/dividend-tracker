# MA1000 首次触及（研究内部，不上站）

`deployable=false`。绝对年化只写在本目录 `summary.json` / `chart.html`，不改 `display_policy`，不接到站点 `#/backtest`。

## 口径

- 价格与均线：前复权收盘；MA = 最近 1000 个交易日简单算术平均。
- 股票池：当前首页可算股息率的 snapshot/watchlist（710 只，dy 非空），历史回溯，**存在幸存者偏差**。
- 信号：先曾收盘相对均线溢价 ≥ 5%，再首次收盘触及或跌破均线（收盘 ≤ 均线）。
- 入场：信号日**次日开盘**买入（不用信号日收盘）。
- 止盈：2% / 5% / 10% / 15% 四档独立。持有期最高价触达则按目标价出（同日可完成）。
- 时间止损：60 个交易日内未触达，按第 60 个交易日收盘出；样本期末不足 60 日则按末日收盘结算，记未命中。
- 再入场：上一笔结束后必须重新站上均线（收盘 > 均线），并再次溢价 ≥ 5%，才接受下一次触及。
- 成本：单边万三（买入、卖出各 0.03%），未计滑点与印花税。
- 样本期：2018-01-01 ～ 最新前复权交易日。

## 组合净值与年化

- 当日有持仓时，对各持仓等权（每日再平衡到等权）；无持仓为现金，收益为 0。
- 年化：`ann_252 = nav_end ** (252 / N) - 1`，N 为样本期全部交易日（含空仓日）。对照口径 `ann_365` 用 365.25 / 日历天数。
- **不要**用每笔平均收益按持有天数直接换算年化。
